# نرتقي بعلاقاتنا — المعلمة مها حلواني

موقع عربي ثابت جاهز للنشر على Render أو GitHub Pages.

## الإضافات
- قسم رؤية السعودية 2030 والتحول الرقمي بلا أوراق.
- خطة دراسية **توضيحية غير معتمدة** للصف الأول المتوسط / لغتي الخالدة، يجب مطابقتها مع المنهج والتقويم الرسمي.
- بطاقات شرح مختصر لمهارات لغوية.
- منصة المعلمة: منشئ **قوالب تحضير محلي**، وليست محادثة AI فعلية. تحتاج المحادثة الفعلية إلى خادم آمن ومفتاح API لا يوضع داخل index.html.

## البصمات
تظل غير مفعلة إلى حين ربط Supabase أو Google Sheets. لا تنشر مفتاحًا سريًا في HTML.

## النشر
