# نرتقي بعلاقاتنا — النسخة المطوّرة

موقع عربي متجاوب للمعلمة مها حلواني، يشمل المبادرة، جدار البصمات، خطة الدروس، المساعد، وملف الإنجاز.

## 1) نشر الموقع
ارفع ملفات `index.html`, `style.css`, `config.js`, `content.js`, `app.js`, `maha-portfolio-qr.png` إلى جذر مستودع GitHub. في Render اختر Static Site وPublish Directory = `.` وBuild Command = `echo ready`. يمكن أيضًا استخدام GitHub Pages.

## 2) البصمات عبر Google Sheets (اختياري)
1. أنشئ Google Sheet خاصًا، ثم Extensions → Apps Script.
2. انسخ محتوى `apps-script/Code.gs` إلى المحرر واحفظه.
3. Deploy → New deployment → Web app، Execute as: Me، Who has access: Anyone. سيطلب الإذن. لا تشارك رابط جدول Sheets نفسه مع الزوار.
4. انسخ رابط Web app الذي ينتهي بـ `/exec` وضعه في `MAHA_SHEETS_URL` داخل `config.js`، ثم أعد نشر الموقع.
5. تظهر الرسائل الجديدة في ورقة `Messages` بحالة `pending`. راجعها ثم غيّر status إلى `approved` لعرضها، أو `rejected` لإخفائها. بعد التفعيل لن تظهر التعليقات التجريبية؛ ستظهر المعتمدة فقط.

**تنبيه:** نموذج الإرسال يستخدم `no-cors`، لذلك يمكنه إرسال الطلب لكنه لا يستطيع تأكيد الحفظ من الاستجابة. اختبر إرسال بصمة وتحقق من ظهورها في الجدول. الوصول العام يعني إمكانية تلقي رسائل مزعجة؛ يوصى بإضافة CAPTCHA أو وسيط محمي قبل إطلاق واسع. لا تنشر بيانات شخصية لطالبات قاصرات دون إذن.

## 3) المساعد الذكي (اختياري)
1. أنشئ Render Web Service من مجلد `ai-service`؛ Build Command: `pip install -r requirements.txt`، Start Command: `gunicorn app:app --bind 0.0.0.0:$PORT`.
2. أضف متغيرات البيئة السرية في Render: `OPENAI_API_KEY`، و`ALLOWED_ORIGINS` بعنوان موقعك الفعلي مثل `https://maha-legacy.onrender.com` (من دون `/` أخيرة). يمكن تحديد `OPENAI_MODEL`.
3. انسخ عنوان خدمة Render (بدون `/` في النهاية) إلى `MAHA_AI_URL` في `config.js`، ثم أعد نشر الموقع.
4. الخدمة تتطلب حساب API بفوترة مستقلة، وقد تكون لها تكلفة. **لا تضع مفتاح API في ملفات GitHub أو JavaScript**.

**أمان الإنتاج:** حد الطلبات الحالي بسيط ويعتمد على ذاكرة العملية، ولا يكفي لمنصة واسعة. قبل الاستخدام العام أضف Rate limiting مركزيًا، CAPTCHA، ومراقبة الاستهلاك، وحماية أقوى ضد إساءة الاستخدام.

## 4) المحتوى التعليمي
عدّل `content.js` لتحديث الخطة والدروس. **الخطة الحالية نموذج توضيحي وليست خطة فصل دراسي معتمدة**؛ تحقق من المنهج والتقويم الرسميين قبل اعتمادها.

## 5) حدود النسخة
- يوجد بحث وتصنيف وتعليقات بعد الاعتماد، لكن لا توجد لوحة تحكم دخول منفصلة؛ الاعتماد يتم من Google Sheets.
- زر «حفظ التحضير» ينزّل ملف TXT؛ ليس تصدير Word أو PDF.
- دون ربط API يعمل نموذج تحضير محلي، وليس محادثة ذكاء اصطناعي حقيقية.
- التعليقات الستة الافتراضية موسومة بأنها أمثلة توضيحية، وليست شهادات حقيقية.
- لم يُجرَ نشر على حساب GitHub أو Render تلقائيًا؛ الملفات جاهزة للرفع.
